# 모델 산출물

학습된 모델, 체크포인트 등 용량이 큰 산출물을 저장합니다. 이 안내 파일과 `.gitkeep`을 제외한 파일은 Git에서 제외됩니다.

모델을 공유할 때는 팀 공유 저장소 위치와 학습 데이터 버전, 설정, 평가 결과를 `reports/`의 실험 기록에 남겨주세요.

지도학습과 강화학습 산출물은 실험 이름으로 구분합니다. 실험 기록에 학습 방식, 코드 버전, 시드, 모델 위치를 남깁니다. 지도학습 모델은 사용한 플레이 기록의 버전을, 강화학습 모델은 전투 환경과 보상 설정을 기록합니다. 규칙 기반 보스는 비교에 사용한 코드 버전과 설정을 기록합니다.

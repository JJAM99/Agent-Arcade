# 데이터 저장 규칙

| 폴더 | 용도 |
| --- | --- |
| `raw/` | 수집한 원본 데이터. 덮어쓰거나 직접 수정하지 않습니다. |
| `external/` | 외부에서 받은 참고 데이터 |
| `interim/` | 정제·변환 중간 결과 |
| `processed/` | 분석 및 모델 입력용 최종 데이터 |
| `samples/` | Git에 올려도 되는 작은 가상·익명화 예시 데이터 |
| `metadata/` | 데이터 출처, 스키마, 수집 방법 기록 |

`raw/`, `external/`, `interim/`, `processed/`의 데이터 파일은 Git에서 제외됩니다. 폴더를 유지하는 `.gitkeep`만 추적합니다. 실제 데이터는 팀에서 정한 공유 저장소로 전달하고 `metadata/datasets.csv`에 위치와 재현 방법을 기록하세요. Git clone만으로 실제 데이터가 내려오지는 않습니다.

`samples/`와 `metadata/`는 Git에 포함됩니다. 개인정보, 비밀번호, 토큰이나 접근용 서명이 포함된 링크는 넣지 마세요. 데이터 사용 권한을 확인한 뒤 샘플을 추가합니다.

## 플레이 기록

지도학습용 기록에는 각 시점의 관측 상태와 플레이어가 선택한 행동을 연결합니다. 기록 형식이 정해지면 스키마와 수집에 사용한 게임 버전을 `metadata/`에 문서화합니다. 학습과 평가를 나눌 때는 같은 플레이 세션이 양쪽에 섞이지 않도록 세션 단위로 분리합니다.
